The MIT license is included in `LICENSE`. Brand marks retain their respective owners. The renderer preserves paths and explicit brand colors, uses white for `currentColor` on dark keys, and adds project/worktree text and state around the mark.

The catalog and shared artwork mappings are in `plugin/plugin/agent-catalog.js`. Lobe Icons assets use the included MIT license. Website and official-repository icons retain their respective owners' rights and are included as product identification marks; the Lobe Icons license does not apply to those assets. Muse, DeepSeek Harness, ZCode and Rovo Dev use their provider marks (Meta, DeepSeek, Z.ai and Atlassian). Raster website icons are embedded as PNG data inside SVG wrappers so runtime rendering stays offline. The Droid viewport is flattened; monochrome Aider and Auggie marks and Autohand strokes use `currentColor` for visibility on dark keys. Autohand animation and theme-dependent CSS are removed for static Qt SVG rendering.
